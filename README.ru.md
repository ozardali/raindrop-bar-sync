# Raindrop Bar Sync

**Одна и та же панель закладок во всех ваших браузерах, через Raindrop.io.**

[English](README.md) · [Türkçe](README.tr.md) · [Deutsch](README.de.md) · **Русский** · [日本語](README.ja.md) · [Español](README.es.md) · [简体中文](README.zh-CN.md) · [Português (BR)](README.pt-BR.md)

Расширение, которое двусторонне синхронизирует **встроенную панель закладок** Chrome, Edge,
Brave, Vivaldi, Helium и Firefox с одной коллекцией Raindrop.io. Добавьте закладку в Firefox,
и через минуту она появится на панели Chrome, в той же папке и на том же месте. Сервером служит
Raindrop; больше ничего размещать не нужно.

## Зачем

- Chrome Sync и Firefox Sync синхронизируют только внутри своего семейства браузеров.
- Собственное расширение Raindrop сохраняет закладки в Raindrop, но не трогает панель
  браузера.
- Инструментам синхронизации закладок между браузерами нужно отдельное хранилище, которое вы
  настраиваете сами (Nextcloud, WebDAV, Google Drive…). Если вы уже пользуетесь Raindrop,
  здесь он и будет таким хранилищем.

## Возможности

- **Двусторонняя синхронизация** панели закладок и её подпапок: добавление, переименование,
  изменение ссылок, перемещение и удаление с любой стороны.
- **Точный порядок**, включая то, как перемешаны папки и закладки. Raindrop сам этого хранить
  не умеет, поэтому порядок лежит в маленьких скрытых заметках в коллекции.
- **Побеждает последнее изменение** для каждой закладки и каждого поля. Учитывается время, когда
  вы действительно его сделали, даже если браузер был офлайн несколько дней.
- **Ничего не теряется случайно**: первая синхронизация только добавляет; папка, удалённая с
  одной стороны, пока в неё что-то добавили с другой, возвращается; массовые удаления
  останавливаются и спрашивают подтверждение.
- **Резервные копии** панели этого браузера перед каждым изменением, восстановление в один клик.
- **Журнал действий** с каждым изменением и его источником («от Firefox»).
- **Список устройств**: все браузеры, синхронизирующиеся с коллекцией.
- **Работа офлайн**: изменения без сети сохраняются и отправляются, когда связь вернётся.
- Всплывающее окно и настройки на **16 языках**, светлая и тёмная тема.
- Без серверов и аналитики, без разрешений сверх `bookmarks`, `storage`, `alarms` и
  `api.raindrop.io`.

## Установка

Расширения пока нет в Chrome Web Store и на addons.mozilla.org; соберите его из исходников.
Нужен [Node.js](https://nodejs.org) 20 или новее.

```sh
git clone https://github.com/ozardali/raindrop-bar-sync.git
cd raindrop-bar-sync
npm install
npm run build            # Chrome, Edge, Brave, Vivaldi, Helium…
npm run build:firefox    # Firefox
```

**Браузеры на Chromium**: откройте `chrome://extensions`, включите **Режим разработчика**,
нажмите **Загрузить распакованное расширение** и выберите `.output/chrome-mv3`.

**Firefox**: откройте `about:debugging#/runtime/this-firefox`, нажмите **Загрузить временное
дополнение…** и выберите `.output/firefox-mv3/manifest.json`. Временные дополнения удаляются
при закрытии Firefox; для постоянной установки выполните `npm run zip:firefox` и подпишите
архив как неопубликованное дополнение на
[addons.mozilla.org](https://addons.mozilla.org/developers/).

## Настройка

1. **Сначала сделайте резервную копию закладок** (диспетчер закладок → Экспорт).
   Синхронизация работает с настоящими данными.
2. В браузерах, где вы используете расширение, отключите встроенную синхронизацию закладок
   (Chrome Sync / Firefox Sync). Две системы на одной панели мешают друг другу и создают
   дубликаты.
3. Нажмите на значок расширения → **Настройки**.
4. **Аккаунт Raindrop**: вставьте тестовый токен. Страница пошагово покажет, как его получить:
   Raindrop → Настройки → Интеграции → *Создать новое приложение* → *Создать тестовый токен*.
   Токен даёт доступ только к вашему аккаунту и не истекает.
5. **Коллекция**: выберите коллекцию, в которой будет отражаться панель, или создайте новую.
   Используйте **одну и ту же коллекцию во всех браузерах**.
6. Готово. Первая синхронизация объединяет обе стороны: добавляет недостающее в обоих
   направлениях и ничего не удаляет.

Дальше изменения в браузере уходят в Raindrop за секунды, а изменения из других браузеров
приходят в течение минуты (интервал настраивается).

## Как это работает

Каждая синхронизация сравнивает три дерева: панель сейчас, коллекцию сейчас и состояние, о
котором обе стороны договорились при прошлой синхронизации. То, что изменилось только с одной
стороны, переносится на другую; если обе стороны изменили одно и то же, побеждает более новое
изменение. Слияние реализовано как чистая функция с модульными, property- и fuzz-тестами: сотни
случайных историй правок, каждая из которых должна заканчиваться одинаковыми сторонами без
потери нового.

Подробности: [docs/architecture.md](docs/architecture.md). Поведение API Raindrop, на котором
построен дизайн, проверенное на настоящем API: [docs/raindrop-api.md](docs/raindrop-api.md)
(на английском).

## Ограничения

- Синхронизируется только панель закладок (и её папки), а не «Другие закладки» или «Мобильные».
- Разделители (Firefox) не синхронизируются: в Raindrop им нет соответствия.
- Ссылки, которые Raindrop не принимает (букмарклеты `javascript:`, `file:`, `about:`),
  остаются в своём браузере и никогда не удаляются.
- Firefox для Android и Safari не поддерживаются.
- Vivaldi и Brave должны работать как Chrome, но пока не проверены.
- Вход выполняется по тестовому токену; «Войти через Raindrop» (OAuth) требует секрета на
  сервере и не реализован.

## Предупреждение

**Это неофициальный проект, не связанный с Raindrop.io и не одобренный им.**

**Синхронизация меняет настоящие данные в двух местах.** Страховки (никаких удалений при
первой синхронизации, пауза перед массовым удалением, локальные резервные копии, корзина
Raindrop) делают потерю закладок маловероятной, но не невозможной. Храните экспорт закладок, к
которому можно вернуться.

**Без гарантий.** Программа предоставляется «как есть» по [лицензии MIT](LICENSE).

## Конфиденциальность

Расширение обращается ровно к одному серверу: `api.raindrop.io`, с вашим токеном. Никакой
аналитики, никаких третьих сторон. Что именно и где хранится, описано в [PRIVACY.md](PRIVACY.md)
(на английском).
